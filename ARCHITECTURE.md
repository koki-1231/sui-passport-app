## 2. チェックイン/チェックアウト設計

### 範囲判定

```typescript
interface CheckinZone {
  id: string;
  name: string;
  center: { lat: number; lng: number };
  radius: number; // メートル
  regionId: number; // 地方DAO紐付け
}

// 範囲内判定（Haversine公式）
function isWithinZone(userLat, userLng, zone): boolean {
  const distance = haversineDistance(userLat, userLng, zone.center.lat, zone.center.lng);
  return distance <= zone.radius;
}
```
